# ADR-0001: Прямые вызовы сервисов без gateway/BFF

- Статус: принято
- Дата: 2026-08-19

## Контекст

В системе два ограниченных контекста: CMS и CRM. Дополнительный gateway дублировал бы
маршрутизацию, авторизацию и DTO, увеличивая число сетевых переходов без отдельной
бизнес-ответственности.

## Решение

Gateway, relay и BFF не вводятся. Next.js отвечает за UI и server actions. Server actions
являются прикладным слоем use cases: читают httpOnly cookie, оркестрируют сценарии и вызывают
CMS/CRM напрямую по `BASE_URL_OF_API_CMS` и `BASE_URL_OF_API_CRM`.

Server actions не являются proxy общего назначения и не скрывают произвольные backend-маршруты.
Prisma Client не используется в React или Next.js; данные проходят через публичные HTTP-контракты
`domain_unified`.

## Последствия

- Границы CMS и CRM остаются явными.
- Кросс-доменные use cases разрешены только в прикладном слое.
- URL сервисов и таймауты задаются окружением.
- Gateway можно пересмотреть только при появлении самостоятельной ответственности: внешнего API,
  централизованной агрегации протоколов или независимой команды эксплуатации.
